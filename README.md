# Online Book Store SQL Project

## Project Overview
This project analyzes an online bookstore database using MySQL.

## Tables
- Books
- Customers
- Orders

## Tools Used
- MySQL
- MySQL Workbench

## SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- JOIN
- Subqueries

## Project Objective
To analyze books, customers, and order data using SQL.
